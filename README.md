# Project: Remote Desktop Application using Java RMI
This project is a remote desktop application developed using Java RMI (Remote Method Invocation), Inspired by tools like AnyDesk or TeamViewer. It allows users to remotely control another computer's desktop in real-time, providing features such as:

* Screen sharing: Transmits the desktop screen from the server machine to the client.
* Remote control: Enables the client to interact with the server’s desktop, including controlling the mouse and keyboard remotely.
* File Transfer: Allows the client and server to exchange files
